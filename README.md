Atividade: Agenda 12 de Desenvolvimento de Sistemas I

## Abrir a página
Baixe a pasta completa e abra index.html em um navegador. Não é necessário instalar bibliotecas ou usar um servidor.

## Conteúdo
Cinco sites: YouTube, Canva, Figma, LinkedIn e Amazon.
Cada site tem um título h1, uma imagem PNG local e um link abaixo da imagem.
A imagem também é clicável. Os links abrem em uma nova aba.
As imagens são ilustrações representativas produzidas para a atividade.

## Arquivos
- index.html: página principal com comentários.
- estilo.css: aparência e adaptação para telas menores.
- Cinco imagens PNG na mesma pasta do HTML.
- captura_pagina.jpg: execução da página no navegador.
- captura_codigo.jpg: captura do código HTML comentado.
- codigo.html: visualizador do código para facilitar a leitura.
